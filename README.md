# Sistema DIF - Proyecto con Docker y GitHub

## Requisitos previos
- Docker Desktop instalado y en ejecución.
- Git instalado.

## Cómo instalar y ejecutar
1. Clonar este repositorio: `git clone <URL-DE-TU-REPO>`
2. Entrar a la carpeta del proyecto: `cd dif_sistema`
3. Levantar los contenedores: `docker compose up -d --build`

## Accesos al sistema
- **Página Web:** http://localhost:8090
- **phpMyAdmin:** http://localhost:8081 (Usuario: root, Contraseña: 12345)
